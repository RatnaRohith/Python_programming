Unit 1: Introduction to Python
1. History of Python Programming Language
What is Python?

Python is a high-level, interpreted, general-purpose programming language known for its simple syntax and readability.

History
Python was created by Guido van Rossum.
Development began in the late 1980s at CWI in the Netherlands.
Python was first released publicly in 1991.
The name "Python" was inspired by the comedy show Monty Python's Flying Circus, not the snake.
Python 2.0 was released in 2000.
Python 3.0 was released in 2008.
Python 2 reached its official end of life in January 2020.
Today, Python 3 is the standard version.
Important features
Simple and readable syntax
Easy to learn
Interpreted
Dynamically typed
Object-oriented
Portable
Open source
Large standard library
Supports multiple programming paradigms
Extensive third-party libraries

Unit 2: Parts of Python Programming Language
5. Identifiers

An identifier is the name given to a programming element such as a variable, function, class, or object.

Example:

name = "Ravi"
age = 20

Here:

name → identifier
age → identifier
Rules for identifiers
Can contain letters, digits and underscore.
Cannot begin with a digit.
Cannot contain spaces.
Cannot use Python keywords.
Identifiers are case-sensitive.

Valid:

student_name
age
marks1
_total

Invalid:

1name
student name
class

10. Operator Precedence and Associativity

Precedence determines which operator is evaluated first.

Example:

result = 10 + 5 * 2

Multiplication is performed first:

10 + (5 × 2)
= 20
Common precedence order

From higher to lower:

()
**
+x, -x
*, /, //, %
+, -
<, <=, >, >=
==, !=
not
and
or
Associativity

Associativity determines the order in which operators having the same precedence are evaluated.

Most operators are left associative.

Example:

20 - 5 - 3

Evaluated as:

(20 - 5) - 3
= 12

Exponentiation is an important exception because it is right associative:

2 ** 3 ** 2

is evaluated as:

2 ** (3 ** 2)

12. Indentation

Indentation means the spaces at the beginning of a line.

Python uses indentation to define blocks of code.

Example:

age = 20


if age >= 18:
    print("Eligible")

The indented statement belongs to the if block.

Incorrect indentation:

if age >= 18:
print("Eligible")

This produces an indentation error.

Usually 4 spaces are recommended for each indentation level.

18. is Operator

The is operator checks whether two variables refer to the same object.

Example:

a = None


print(a is None)

Output:

True

Important distinction:

== 

checks value equality.

is

checks object identity.

19. Python as a Dynamically Typed Language

Python is dynamically typed because we do not need to specify a variable's type when creating it.

x = 10
print(type(x))


x = "Hello"
print(type(x))

The type associated with x changes depending on the object assigned to it.

20. Python as a Strongly Typed Language

Python is strongly typed because it does not automatically perform arbitrary conversions between incompatible types.

Example:

x = 10
y = "20"


print(x + y)

This produces a TypeError.

We need explicit conversion:

print(x + int(y))

Output:

30
Dynamic vs Strong typing
Concept	Meaning
Dynamically typed	Variable type need not be declared
Strongly typed	Incompatible types are not freely mixed
Unit 3: Control Flow Statements

Control flow determines the order in which program statements are executed.

21. if Statement

Used when a block should execute only when a condition is true.

Syntax:

if condition:
    statement

Example:

age = 20


if age >= 18:
    print("Eligible to vote")
22. if-else Statement

Used when there are two possible paths.

age = 16


if age >= 18:
    print("Eligible")
else:
    print("Not eligible")
23. if...elif...else

Used when there are multiple conditions.

marks = 75


if marks >= 90:
    print("Grade A")
elif marks >= 75:
    print("Grade B")
elif marks >= 60:
    print("Grade C")
else:
    print("Grade D")

Only the first matching condition is executed.

24. Nested if

An if statement inside another if statement is called a nested if.

Example:

age = 20
citizen = True


if age >= 18:
    if citizen:
        print("Eligible to vote")
25. while Loop

A while loop repeatedly executes a block as long as a condition is true.

Syntax:

while condition:
    statements

Example:

i = 1


while i <= 5:
    print(i)
    i += 1

Output:

1
2
3
4
5
26. for Loop

A for loop is commonly used to iterate over a sequence or other iterable.

Example:

for i in range(1, 6):
    print(i)

Output:

1
2
3
4
5

Iterating over a string:

for ch in "Python":
    print(ch)
27. break Statement

break terminates the loop immediately.

Example:

for i in range(1, 10):
    if i == 5:
        break
    print(i)

Output:

1
2
3
4
28. continue Statement

continue skips the current iteration and proceeds to the next iteration.

Example:

for i in range(1, 6):
    if i == 3:
        continue
    print(i)

Output:

1
2
4
5
break vs continue
break	continue
Terminates the loop	Skips current iteration
Control exits the loop	Control moves to next iteration
29. Exception Handling Using try and except

An exception is an error that occurs during program execution.

Python provides try and except to handle exceptions.

Example:

try:
    a = int(input("Enter a number: "))
    b = int(input("Enter another number: "))


    result = a / b
    print(result)


except ZeroDivisionError:
    print("Cannot divide by zero")


except ValueError:
    print("Please enter valid numbers")
Structure
try:
    # Code that may cause an exception
except:
    # Code that handles the exception
Why exception handling is important

Without exception handling, an error can terminate the program.

With exception handling, we can:

Detect errors
Handle errors gracefully
Display meaningful messages
Continue program execution where appropriate
