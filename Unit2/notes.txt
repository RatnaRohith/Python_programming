1. Functions in Python

A function is a reusable block of code that performs a specific task.

1.1 Built-in Functions

Python provides many functions that can be used directly.

print("Hello")
len("Python")
max(10, 20, 30)
min(10, 20, 30)
sum([10, 20, 30])
type(10)

Common built-in functions:

Function	Purpose	Example
print()	Displays output	print("Hello")
input()	Reads input	input("Enter: ")
len()	Returns length	len("Python")
type()	Returns data type	type(10)
max()	Largest value	max(10, 20)
min()	Smallest value	min(10, 20)
sum()	Calculates total	sum([1,2,3])
abs()	Absolute value	abs(-10)
round()	Rounds number	round(3.14159, 2)
1.2 Commonly Used Modules

A module is a Python file containing functions, classes, and variables that can be imported and reused.

math module
import math


print(math.sqrt(25))
print(math.pow(2, 3))
print(math.pi)

Output:

5.0
8.0
3.141592653589793
random module
import random


print(random.randint(1, 10))

This generates a random integer between 1 and 10.

datetime module
import datetime


today = datetime.date.today()
print(today)
2. Function Definition and Calling
Syntax
def function_name():
    statements
Example
def greet():
    print("Hello Students")


greet()

Here:

def → keyword used to define a function
greet → function name
() → parameter list
: → starts the function body
greet() → calls the function
Function with parameters
def greet(name):
    print("Hello", name)


greet("Ravi")
greet("Anil")

Output:

Hello Ravi
Hello Anil
3. return Statement

The return statement sends a value back to the calling code.

def add(a, b):
    return a + b


result = add(10, 20)


print(result)

Output:

30
Difference between print() and return
def add1(a, b):
    print(a + b)


def add2(a, b):
    return a + b

print() displays a value, while return sends the value back so it can be stored or used in another expression.

x = add2(10, 20)
print(x * 2)

Output:

60
4. Void Function

A function that does not explicitly return a value is commonly called a void function.

def display():
    print("Welcome to Python")


display()

Technically, Python returns None when no value is returned.

def display():
    print("Hello")


x = display()


print(x)

Output:

Hello
None
5. Scope and Lifetime of Variables
Local Variable

A variable created inside a function is normally local to that function.

def demo():
    x = 10
    print(x)


demo()

x cannot normally be accessed outside the function.

Global Variable

A variable created outside a function is global.

x = 100


def display():
    print(x)


display()

Output:

100
Example
x = 10


def demo():
    x = 20
    print("Inside:", x)


demo()


print("Outside:", x)

Output:

Inside: 20
Outside: 10

The local variable and global variable are different variables.

6. Default Parameters

A parameter can have a default value.

def greet(name="Student"):
    print("Hello", name)


greet()
greet("Ravi")

Output:

Hello Student
Hello Ravi

Another example:

def power(number, exponent=2):
    return number ** exponent


print(power(5))
print(power(5, 3))

Output:

25
125
7. Keyword Arguments

Arguments can be passed using parameter names.

def student(name, age):
    print("Name:", name)
    print("Age:", age)


student(age=20, name="Ravi")

The order does not matter when keyword arguments are used.

8. *args

*args allows a function to accept a variable number of positional arguments.

def add(*numbers):
    total = 0


    for n in numbers:
        total += n


    return total


print(add(10, 20))
print(add(10, 20, 30, 40))

Output:

30
100

Inside the function, args is stored as a tuple.

9. **kwargs

**kwargs allows a function to accept a variable number of keyword arguments.

def student(**details):
    print(details)


student(name="Ravi", age=20, branch="CSE")

Output:

{'name': 'Ravi', 'age': 20, 'branch': 'CSE'}

kwargs is stored as a dictionary.

Difference
*args     → variable positional arguments → tuple
**kwargs  → variable keyword arguments  → dictionary
10. Command Line Arguments

Command-line arguments are values passed to a Python program when it is executed.

Python provides the sys module for accessing them.

Program
import sys


print("Program name:", sys.argv[0])
print("First argument:", sys.argv[1])
print("Second argument:", sys.argv[2])

Run:

python program.py Hello Python

Output:

Program name: program.py
First argument: Hello
Second argument: Python

sys.argv is a list containing command-line arguments.

16. Joining Strings

The join() method combines multiple strings.

words = ["Python", "is", "easy"]


sentence = " ".join(words)


print(sentence)

Output:

Python is easy

Another example:

numbers = ["10", "20", "30"]


result = "-".join(numbers)


print(result)

Output:

10-20-30

18. Formatting Strings
Using f-strings

My name is Ravi and I am 20 years old.
Expressions inside f-strings
a = 10
b = 20


print(f"Sum = {a + b}")

Output:

Sum = 30

extend()

Adds multiple elements.

numbers.extend([50, 60])

Removes a specified element.

26. del Statement

The del statement can delete an element, multiple elements, or an entire variable.

Delete one element
numbers = [10, 20, 30, 40]


del numbers[1]


print(numbers)

Output:

[10, 30, 40]
Delete a range
numbers = [10, 20, 30, 40, 50]


del numbers[1:4]


print(numbers)

Output:

[10, 50]
Delete the entire list
numbers = [10, 20, 30]


del numbers

After this, numbers no longer exists.
